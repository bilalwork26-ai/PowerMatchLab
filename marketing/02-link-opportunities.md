# Link & Distribution Opportunities — Research Notes

## How this list was built, and its real limitation

Every URL below came from a live web search run in this session (not invented, not remembered from training). **What I could not do: open any individual page to read its actual posted rules on self-promotion or affiliate links** — this environment's outbound web-fetch access is blocked at the network level for all external domains (confirmed by testing several, including the ones below and the IndexNow API itself). So for every entry, the **Name / URL / apparent audience** is real and search-verified; the **visible self-promo policy** column is marked "not verified — could not open the page" unless a general, well-established platform-wide rule is cited instead (e.g., Reddit's sitewide content policy, which is common knowledge, not something I fetched).

**Before posting anywhere on this list, whoever has an account there should personally open the page and read its actual current rules.** Do not treat this table as pre-cleared.

Every "not verified" above means exactly that: the community is real (confirmed via search), but its specific policy was not read by me.
- I did not create any account on any of these platforms, and did not post anything. Doing so requires a person with real access and authority to act on the site owner's behalf, per this round's explicit rules.
- I did not find or invent contact names or email addresses for the blogs listed — the editorial outreach templates in `05-editorial-outreach.md` are addressed generically ("Hi [Name]" / "the editorial team at [Site]") for exactly this reason; whoever sends them needs to find the real contact first (an About/Contact page, a byline, or a masthead — something I could not fetch here either).
