"Day 1" = whatever day you actually start executing this. The weekday pattern (Mon–Sun) is a suggested rhythm, not tied to a specific calendar date — shift the whole grid to match when you begin. All content referenced here is in the other files in this `marketing/` folder — this calendar just sequences it.

**Status column:** mark each row `Not started` / `Posted` / `Skipped` as you go — this file is meant to be edited in place as a working tracker, not a one-time plan.

## What "done" looks like at Day 30

That read is what decides Month 2's plan — this file doesn't presume the answer in advance.
